| S-03 | **Stripe webhook swallows exceptions and returns 200.** Fee marked delivered by Stripe, never marked paid in DB. The milestone branch (`server.py:575-588`) shares the same TOCTOU shape, but its follow-on writes are idempotent `$set` (status="paid", paid_at) — no money-loss vector today, only `paid_at` restamped by every winner. `test_concurrent_milestone_replay_is_still_idempotent` in `test_17_milestone_payments.py` documents this as a passing invariant; if a future revision adds a `$inc` in that branch (commissions, ledger, credit-hours-back), it inherits the bug. | `server.py:557-598`, esp. `573-575` (swallow) and `590-595` (TOCTOU) | (a) Return 500 on handler failure so Stripe retries — replace the dispute-branch swallow with a raise. Apply the same shape to the milestone branch preemptively. |
